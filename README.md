# Open Corporate Graph

A free, browser-based corporate relationship explorer using public data sources.

## Features
- Search companies, people, addresses, and LEIs
- Click any graph node to expand one hop
- GLEIF legal-entity and accounting-hierarchy data
- Wikidata people, organization, headquarters, affiliation, and reverse-role links
- Collision-aware graph layout
- Full-graph PNG export
- No OpenCorporates dependency
- No paid API required

## Live site
This repository is configured for GitHub Pages through GitHub Actions.

## Data notes
Coverage depends on what each public source reports. A missing relationship means the connected source did not return one; it does not prove that no relationship exists.
